# 词间

一个用于电脑浏览器的图文背词网页。按章节查看单词、释义、配图和例句，也可以进行回忆练习。学习进度保存在当前浏览器。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

在浏览器打开命令行显示的地址。需要生成静态网页时运行 `npm run build`，结果在 `dist/`。

## 内容来源

配图与课程来自本项目的个人素材。部分参考内容来自 [Word Atlas](https://github.com/designfuchen/word-atlas)（CC BY 4.0，节选）、[ECDICT](https://github.com/skywind3000/ECDICT)（MIT）、[WordNet](https://wordnet.princeton.edu/license-and-commercial-use)、[Wiktionary](https://en.wiktionary.org/) 和 [Tatoeba](https://tatoeba.org/)；例句及词典来源也标在页面中。部分内容由 AI 生成，尚未逐条校对。
